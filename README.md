# Portfolio Website — VS Code Version

This is a responsive HTML/CSS/JavaScript recreation inspired by the portfolio URL supplied in the conversation.

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` → **Open with Live Server**.
4. Edit your name, bio, links, projects, certificates and university details in `index.html`.

## Important
The image URLs currently point to the supplied portfolio's public image paths so the layout can be previewed immediately. For a permanent deployment, download your own images into `assets/` and replace those URLs with local paths such as `assets/profile.jpg`.

Add your resume as `assets/resume.pdf` for the Download Resume button to work.
